# JS Quiz

This is a small quiz app I made with JavaScript. It asks 5 questions about JavaScript basics and shows your score at the end.

## How it works

You click Start Quiz, answer each question by clicking one of the options, and see your score when you finish. A short message is shown based on how well you did. The Play Again button starts the quiz over.

## Tech stack

- HTML for the page
- CSS for the styling
- Vanilla JavaScript for the quiz logic (questions, answers, score)

## How to run

No setup needed. Open `index.html` in a browser.

I tested it by opening the file in Chromium and clicking through the full quiz: all 5 questions, correct and wrong answers, and the final score. It works.
